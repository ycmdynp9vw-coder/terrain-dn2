TERRAIN

Wave terrain synthesis. 8 banks of 8 lands, warp, an FM-style MOD, phase distortion, land shaping (aspect, rotation, erosion, ridge, wind, feedback), a DRUM page with pitch sweep and filtered noise, sync and key tracking. Right below SWARMER.

Processors
The Digitone II has two brains. A ColdFire MCF54415 runs the screen, the buttons, the sequencer and the settings: TERRAIN's pages, NEGATIVE SCREEN, MOD GRAPHICS and the ported mods live here. A SHARC+ ADSP-21569 DSP makes the sound: TERRAIN's voices run here, next to Elektron's machines.

DSP load
Sound is made in blocks of 32 samples at 48 kHz, 1,500 blocks a second. Eight TERRAIN voices at once take 76% of a block in the emulator, under the 85% line every build is tested against.
8 voices · 76%85% limit
Memory
Everything runs from the Digitone's 128 MB of DDR, like the stock OS. NEGATIVE SCREEN and MOD GRAPHICS use 2 bytes at the end of the settings block, so they are remembered after a restart.
Untouched
The bootloader, the updater, the boot data and the file's meta section are byte-identical to Elektron's 1.12. Only the main OS and the DSP image change, so the way back is always a normal OS update.
Checked
Built with digikit's patchkit, which checks every instruction against what each processor can run. The page then rebuilds both sections from your file, compares them byte for byte with the tested build and runs all 22 of Elektron's own integrity checks before you can download.
